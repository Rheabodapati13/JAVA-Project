# JAVA-Project

Designing a Scientific Calculator

This project consists of the design and implementation of a Scientific Calculator. Using Java, this application is built to support various arithmetic (+, -, *, /) and scientific functions (Trigonometry, exponents, etc).

The project demonstrates concepts and application of Java ranging from the basic concepts, Object- Oriented Programming (OOPs) and exception-handling.

The project implements a scientific calculator as a desktop application, allowing the users  to interact with it similar to a physical calculator.

Technologies Used:

Java Development Kit (JDK), Java Swing for GUI components, Java Math class for scientific functions, java.awt for layout management and event handling.
